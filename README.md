# Tek Zanith — Interactive 3D Portfolio & Executive CV

Senior QA Automation Engineer | AI & Test Architecture Lead

Live interactive portfolio built with Three.js WebGL and vanilla modern web technologies.

## Features
- **3D Interactive Career Trajectory**: Built using Three.js with orbit controls and responsive geometry.
- **Background Ambient Particle Canvas**: Lightweight WebGL particle system.
- **Executive Resume**: 2-page print-optimized and downloadable PDF.
- **High Performance & Zero Dependencies**: Fast load times, responsive across mobile, desktop, and foldable viewports.

## Deployment
- Hosted on Vercel / GitHub Pages.
